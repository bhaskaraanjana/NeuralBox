# RAG Demo Pack

This folder contains ready-to-upload documents for a live NeuralBox RAG demo.

## Files
- `docs/incident_response_playbook.txt`
- `docs/enterprise_data_policy.txt`
- `docs/product_roadmap_summary.txt`
- `docs/customer_success_faq.txt`

## Quick Use
1. Open NeuralBox.
2. Go to `Settings -> Regular -> Local RAG`.
3. Click `Clear All`.
4. Add all files from `demo/rag/docs`.
5. Ask questions from `doc/RAG_DEMO_PLAYBOOK.md`.

## Why this pack works
- Includes uniquely identifiable facts for easy retrieval checks.
- Includes cross-document overlap for synthesis.
- Includes intentional scope differences (standard vs enterprise retention) to test reasoning quality.
